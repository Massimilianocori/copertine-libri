Note esplicative Istat ATECO 2025[1]

63.91.00 Attività dei portali di ricerca sul web

EN Web search portal activities · DE Web-Suchportale

Comprende

  • gestione di siti web che utilizzano un motore di ricerca per generare e mantenere ampi database di indirizzi e contenuti Internet in un formato facilmente consultabile; i portali di ricerca sul web non sono responsabili dei contenuti
  • gestione di siti web di confronto di prezzi, specifiche di prodotti, eccetera, con fornitura di collegamenti ad altri siti web

Comprende anche

  • fornitura a terzi di dati provenienti da portali di ricerca sul web senza servizi di elaborazione dati
