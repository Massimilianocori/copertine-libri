SIC to NAICS: the NAICS code for every SIC code

Type a SIC code or a word: 1,005 SIC codes of 1987 with the official 1997 NAICS codes and the 2022 codes they lead to.

For each four-digit 1987 SIC code: the 1997 NAICS codes of the official Census concordance, part by part, and the 2022 codes reached by following the official concordances 1997 → 2002 → 2007 → 2012 → 2017 → 2022.[1],[2],[3],[4],[5],[6]

The only official SIC ↔ NAICS concordance of the Census Bureau is between 1987 SIC and 1997 NAICS. The step from 1997 to 2022 is our chaining of the later official concordances: when a NAICS industry was split or merged after 1997, a SIC code can lead to several 2022 codes. Read the descriptions and check with the agency or form that asks for the code.

Frequently asked questions

Questions people really search on Google, answered from the official sources cited.

What is a SIC code?

A code of the Standard Industrial Classification, the U.S. industry classification of 1987 that NAICS replaced in 1997. SIC codes have four digits: the Census Bureau concordance lists 1,005 four-digit SIC industries, grouped in two-digit major groups such as 73 «Business services».[1],[7]

How do I convert a SIC code to a NAICS code?

The Census Bureau's concordance links each 1987 SIC code, or each part of it, to 1997 NAICS codes. To reach the 2022 codes, this table follows the official concordances 1997 → 2002 → 2007 → 2012 → 2017 → 2022 step by step. When a SIC code was split, read the part descriptions and the description of each NAICS code to see which one fits the activity.[1],[2],[8]
