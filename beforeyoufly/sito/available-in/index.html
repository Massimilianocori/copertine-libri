How we check

We include a service only if the provider itself publishes a list of countries that we can read without a browser, and we read it again before every update. Services whose list exists only inside an app or a script, or that block automated reading, are left out. Country names are matched to ISO 3166-1 codes; regions inside a country (for example the Canary Islands) are not shown separately. More on the About page. Spotted a change? Tell us.
